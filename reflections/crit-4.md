# Crit 4 — VOX-8

## What was the breakthrough that moved the work forward?

The breakthrough is about my understanding of how to express the rhythm in my
plain words. I don't understand music, so I don't know how to express my design
to the agent. Yet I know I can express it in my plain words, like high frequency,
buzzing, warm and smooth, which allows me to pass my design in a way the agent
can understand. And the second breakthrough is adding components which allow me
to adjust Sustain, Decay and Tone, other than the original 8 sounds.

## What did this work change about who I want to be as a software developer?

Music is my weakness, so I seek help from agents, and the answer is that I do not
need to really know music — I can express it by my intuition. However, for a
software developer who knows music, the expression would be more natural and more
efficient.

I added instruction files in the instructions folder, and I used them to provide
precise control for the agent to understand the detail of the implementation.

I guided the agent using adjectives, "a bit sharp, a bit electronic", as an
aesthetic judgement. I detected the polyphony bug and fixed it by limiting the
maximum value to 12. I designed the layout with reference to the Pip-Boy in
Fallout. I dropped the loop feature, because it focuses on operating, not
playback.
